# Quality Checklist

Check every video against this list before publishing.

- [ ] Script is accurate and matches the course content
- [ ] Runtime is about one minute
- [ ] Correct avatar for the market (India or Iraq)
- [ ] Names and terms are pronounced correctly
- [ ] Captions match the audio
- [ ] Visual style matches the rest of the series
- [ ] Filename follows the naming pattern in the production guide
- [ ] Final version is saved and logged
