# Production Guide

## 1. Script
- Keep each video to about one minute (roughly 130 to 150 words).
- Structure: a hook in the first 5 seconds, the core explanation, one takeaway, and a closing line.
- Use plain language suited to students.

## 2. Presenter and images
- Use the approved avatar for the market: Professor Money or Professor Maya for India, and the two new avatars for Iraq.
- Create background and supporting images in ChatGPT or Microsoft Copilot. Keep the style, colors, and framing consistent across each series.
- Save final images with the video ID in the filename, for example `IN-M05-bg.png`.

## 3. Avatar video in HeyGen
- Use the same avatar and settings for every video in a series.
- Paste the approved script, check pronunciation of names and terms, and generate the video.
- Export at the agreed resolution and save the file with its video ID.

## 4. Editing with Claude
- Use Claude to tighten scripts, fix captions, and draft on-screen text.
- Keep a record of the final approved script for each video.

## 5. Naming and storage
- Use this filename pattern: `[MARKET]-[COURSE]-[NUMBER]-[version].mp4`
- Example: `IN-C0039-05-v1.mp4`

## 6. Quality checks
Use the checklist in `docs/quality-checklist.md` before any video is published.
